Wie funktioniert das Projekt?

Eine Lichtquelle beleuchtet eine Wasserprobe. Ein Sensor misst das Licht, das die Probe durchdringt. Die Messwerte können anschließend ausgewertet werden, um Veränderungen der Wasserprobe zu erkennen.
